# Live Vision demo asset

The dashboard expects the temporary conveyor demo video at:

`frontend/public/conveyor_1.mp4`

The frontend serves it as `/conveyor_1.mp4` and loops it muted inside the Live Vision panel. If the file is missing, the existing generated conveyor scene remains visible as a fallback.

Current reference asset properties: 1280x720, H.264, 24 FPS, 8 seconds.
